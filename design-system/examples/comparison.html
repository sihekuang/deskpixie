Choosing a local database

SQLite vs DuckDB vs Postgres for a single-user desktop app

Recommendation: SQLite

It ships inside the app, needs no server and handles this workload with room to spare. Add DuckDB later only if analytics queries become slow.

Risk: concurrent writers

SQLite allows one writer at a time. Use WAL mode and keep transactions short.

Ruled out: Postgres

A server process for a single-user app adds install, upgrade and backup work for no gain.
