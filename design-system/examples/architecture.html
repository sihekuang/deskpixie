DeskPixie architecture

High-level design: who talks to whom, and where the trust boundaries are

flowchart LR
  user([You]) -- voice --> voice[Voice loop]
  subgraph app [DeskPixie app]
    voice -- state, mouth --> pixie[Pixie window]
    voice -- delegate --> agent[Agent]
    agent -- writes HTML --> pages[(canvas/pages)]
    pages -- polled every 500 ms --> canvas[Canvas window]
  end
  voice <-- realtime audio --> model{{Realtime model}}

Components

ComponentResponsibilityTalks toTrust
Voice loopHotkey, mic and speaker, conversation stateRealtime model, pixie, agentapp
Pixie windowDraws Pixie and its statesEvents from the app onlyapp
AgentLong tasks; writes canvas pagesPages folderdelegated
Canvas windowShows one agent-written pageNothing: no IPC, no networksandboxed

Why the canvas is safe

A strict CSP blocks every network request, the window has no IPC permissions, and navigation away from the page is refused.

The only interface is a folder

Any agent that can write a file can draw on the canvas. There is no code dependency between the agent and the app.
