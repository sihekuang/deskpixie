# Parity (Phases 4 + 5) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development. Each work package (WP) is one implementer dispatch. Steps use checkbox (`- [ ]`) syntax.

**Goal:** DeskPixie reaches feature parity with ai-mascot (origin/main 33dcf70): every behaviour in `docs/parity/voice-app-inventory.md` and `docs/parity/delegation-inventory.md` has a home in Go or Swift with its Rust tests ported and passing.

**Architecture:** Builds on Phase 3 (`docs/superpowers/plans/2026-10-13-phase3-skeleton.md`). Go owns settings, app state, voice, tools, canvas logic, packs and delegation; Swift owns windows, tray, audio devices, hotkey, notifications. One new generic C entry point, `dp_call(method, argsJSON)`, carries all request/response traffic; Go → Swift traffic stays on `dp_poll_event`. This keeps the C header fixed while WPs add methods and events.

**Tech Stack:** Go 1.26.2 (stdlib-first; `github.com/coder/websocket`; an expression evaluator for `calculate` chosen in P3), Swift 6 / SwiftUI / AppKit / WebKit / CoreAudio / UserNotifications, xcodegen.

**Spec:** `docs/specs/2026-10-13-deskpixie-port-design.md` (§3 inventory, §5 Phases 4–5, §6 rename + migration).

## Shared contract: `dp_call` and events

C (added to `libdeskpixie_shim.h`, stubs, and `core/cmd/libdeskpixie`):
```c
char* dp_call(char* method, char* args_json);   // returns {"ok":<json>} or {"error":"<msg>"}; free with dp_free_string
```
Go: `core/bridge` keeps a registry `Register(method string, fn func(args json.RawMessage) (any, error))`; packages register their methods at engine build. Swift: `CoreEngine.call(_ method: String, _ args: Encodable) throws -> Data`.

Methods (owner WP in brackets):
| Method | Args → Result |
|---|---|
| `settings.snapshot` [P1] | `{}` → Snapshot `{platform, values, fields, restartPending, fileError, warning, seq}` |
| `settings.set` [P1] | `{field, value}` → Snapshot (error text per field inside Snapshot, like Rust) |
| `settings.reload` [P1] | `{}` → Snapshot |
| `settings.secrets` [P1] | `{}` → `{"openai":"found|missing","gemini":"found|missing"}` |
| `settings.choices` [P1] | `{field, choices:[{value,label}]}` → `{}` (Swift supplies device lists) |
| `app.state` [P14] | `{}` → AppState (tray model, below) |
| `app.action` [P14] | `{id}` → `{}` (Rust menu ids: `state:<n>`, `talk`, `size:<n>`, `reset-position`, `fade`, `pack:<id>`, `reload`, `canvas:open`, `canvas:page:<slug>`, `canvas:folder`, `agent:cancel:<id>`, `agent:open`, `agent:restart`) |
| `mascot.click` [P14] | `{}` → `{}` (opens agent terminal) |
| `mascot.moved` [P14] | `{x,y}` → `{}` (logical top-left, saved as `position`) |
| `canvas.resolve` [P5/P14] | `{path}` → `{status, contentType, file?, headers:{...}}` (Swift reads `file`; Go enforces caps) |
| `canvas.geometry` [P14] | `{x,y,width,height}` → `{}` |
| `audio.deviceChanged` [P14] | `{}` → `{}` (ends conversation with AudioDeviceChanged) |

AppState: `{state, packs:[{id,name}], pack, scale, fade, talking, canvasRecent:[{slug,title}], agent:{enabled, jobs:[{id,label}]}, statusLines:[string], hotkey}`.

Events (`dp_poll_event`, JSON `kind` + fields), in addition to Phase 3's `state`, `mouth`, `status`, `transcript`, `error`, `mic`, `metrics`:
| kind | fields | Swift action |
|---|---|---|
| `tray` | — | re-read `app.state`, rebuild menu |
| `pack` | `pack`, `sheetPath`, `scale`, `hitMask` (base64 bitset, cell w×h, row-major) | reload mascot |
| `position` | `x?`, `y?` (absent = default spot) | move panel |
| `hotkey` | `combo` | rebind (Swift reports failure via `settings.set` warning path: see P1) |
| `devices` | `input?`, `output?` (UIDs) | pin for next start |
| `notify` | `title`, `body`, `sound` (`glass`/none) | UNUserNotification + sound |
| `canvas.open` | `url`, `title` | show canvas window |
| `settings.changed` | — | settings window refreshes |
| `restart` | — | relaunch app |
| `chime` | handled in Go (samples into playback queue) | — |
